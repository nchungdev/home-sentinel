# Task M2-T2.2: Xây dựng Pipeline Orchestrator và Legacy Adapter

## Mục tiêu
Dựng khung điều phối `Orchestrator` tuần tự qua các tầng độc lập và tạo `LegacyAdapter`
để endpoint cũ `/ask` tiếp tục hoạt động ổn định và tương thích 100% với TV client hiện hành.

## Nội dung công việc
1. Xây dựng package Go `orchestrator` (`home-sentinel/agent/pkg/orchestrator`):
   - Định nghĩa 4 interface độc lập:
     + `UnderstandingEngine`: `Parse(ctx context.Context, input *contracts.InputEvent, reqCtx *contracts.RequestContext) (*contracts.Intent, error)`
     + `ResolutionEngine`: `Resolve(ctx context.Context, intent *contracts.Intent, reqCtx *contracts.RequestContext) (*contracts.ActionPlan, error)`
     + `ExecutionEngine`: `Execute(ctx context.Context, step *contracts.ActionStep, reqCtx *contracts.RequestContext) (*contracts.ExecutionResult, error)`
     + `PresentationComposer`: `Compose(ctx context.Context, input *contracts.InputEvent, intent *contracts.Intent, plan *contracts.ActionPlan, results []*contracts.ExecutionResult, reqCtx *contracts.RequestContext) (*contracts.PresentationResponse, error)`
   - Cấu trúc `Orchestrator` liên kết 4 thành phần trên.
   - Phương thức `Process(ctx, input, reqCtx)`: điều phối tuần tự
     Understanding -> Resolution -> Execution (tuần tự từng bước, dừng khi bước lỗi không retry)
     -> Presentation.
   - Hỗ trợ hủy nhanh khi context bị timeout hoặc hủy qua `ctx.Done()`.
2. Xây dựng `LegacyAdapter` trong Go (`home-sentinel/agent/pkg/transport/legacy.go`):
   - Tiếp nhận format request cũ của `POST /ask`: `{"text": "...", "session": "..."}`.
   - Khởi tạo `contracts.InputEvent` và `contracts.RequestContext` để gọi `Orchestrator.Process()`.
   - Chuyển đổi `contracts.PresentationResponse` thành chunked stream `text/plain` tương thích 100%
     với TV client hiện hành (`AgentClient.kt` và WebView `answer.js`).
   - Hỗ trợ xuất text lời nói kèm khối HTML Card (`<div class="card"...`) trong `<div class="grid">`.
3. Viết bộ unit test toàn diện:
   - `orchestrator_test.go`: 8 test cases kiểm thử pipeline tuần tự, dừng khi step lỗi, timeout context,
     lỗi understanding, resolution và validation.
   - `legacy_test.go`: 12 test cases kiểm thử gửi request `/ask`, chunked stream, render HTML card,
     kiểm tra token/IP whitelist, xử lý lỗi và tái tạo chuỗi stream chính xác.

## Tiêu chí hoàn thành (DoD)
- Điều phối tuần tự qua 4 tầng bằng interface trừu tượng, không phụ thuộc cứng.
- Dừng bước thực thi ngay khi gặp lỗi không thể thử lại và chuyển kết quả sang Presentation.
- Endpoint `/ask` tương thích hoàn toàn định dạng TV client mong đợi.
- Mã nguồn tuân thủ: 0 comments, tên biến tường minh, dòng <= 100 ký tự.
- Vượt qua 100% unit test và các khâu kiểm thử nghiệm thu.
