# Task M1-T1.3: Bộ Fixtures Kiểm thử Tương thích Hợp đồng & Go Contracts

## Mục tiêu
Tạo bộ mẫu JSON fixtures (hợp lệ và không hợp lệ) để kiểm tra tính tương thích dữ liệu giữa
backend và client Android, đồng thời xây dựng package Go hợp đồng dữ liệu chuẩn hóa
(`agent/pkg/contracts`) phục vụ kiến trúc Go nhẹ trên NAS theo chỉ đạo kiến trúc.

## Nội dung công việc
1. Xây dựng Package Go Hợp đồng Dữ liệu (`home-sentinel/agent/pkg/contracts`):
   - `ActionStatus`: `ActionStatusAccepted`, `ActionStatusRunning`, `ActionStatusNeedsInput`,
     `ActionStatusSucceeded`, `ActionStatusFailed`, `ActionStatusCancelled`, `ActionStatusUnknown`.
   - `InputEvent`, `RequestContext`, `Intent`, `ActionStep`, `ActionPlan`, `ExecutionResult`,
     `PresentationResponse`, `Suggestion`, `ContextSnapshot`, `ProactiveChip`.
   - Các phương thức helper `ToJson()`, `FromJson()`, `ToJSON()`, `FromJSON()` và `Validate()`.
2. Tạo bộ JSON fixtures dùng chung:
   - `agent/pkg/contracts/fixtures/` và `apps/launcher/app/src/test/resources/fixtures/contracts/`:
     - `input_event_valid.json`, `input_event_invalid.json`
     - `intent_valid.json`
     - `action_plan_valid.json`
     - `presentation_response_valid.json`
     - `suggestion_valid.json`
     - `context_snapshot_valid.json`
     - `proactive_chip_valid.json`, `execution_result_valid.json`
3. Viết Unit test kiểm tra tương thích:
   - Go: `contracts_test.go` đọc fixtures, kiểm tra unmarshal, validate, marshal và đối chiếu.
   - Kotlin: `AgentContractsTest.kt` nạp và parse toàn bộ fixtures từ classpath test resources.
   - Python: `test_contracts.py` bổ sung `ContractFixturesTest` nạp và xác thực fixtures.

## Tiêu chí hoàn thành (DoD)
- Package Go `agent/pkg/contracts` biên dịch sạch và pass 100% tests.
- Unit test parse fixtures chạy thành công 100% trên Go, Python và Kotlin Android.
- Không vi phạm quy chuẩn code style và line limit (100 ký tự).
