# Task M3-T3.1: Tách Module Understanding

## Mục tiêu
Xây dựng package Go `understanding` (`home-sentinel/agent/pkg/understanding`) hiện thực interface
`orchestrator.UnderstandingEngine`: chuẩn hóa tiếng Việt, xử lý từ điển ngữ âm
("anh trai c2" -> "Anh Trai Say Hi", "a ven dơ" -> "Avengers"), bóc tách nguồn chỉ định rõ ràng
(YouTube, Plex), phân loại ý định qua Regex/từ khóa mà không phụ thuộc bất kỳ API mạng nào.

## Nội dung công việc
1. Xây dựng package Go `understanding` (`home-sentinel/agent/pkg/understanding`):
   - Hiện thực interface `orchestrator.UnderstandingEngine`:
     `Parse(ctx context.Context, input *contracts.InputEvent, reqCtx *contracts.RequestContext)`
     `(*contracts.Intent, error)`
   - Từ điển ngữ âm `phoneticRules` với ranh giới Unicode (`\p{L}`, `\p{N}`):
     + "anh trai c2", "anh trai say hai", "anh trai xe hai" -> "Anh Trai Say Hi"
     + "a ven dơ", "ơ ven gơ", "aven gơ", "aven dơ" -> "Avengers"
     + "en gêm", "end gêm" -> "Endgame"
     + "úp pen hay mơ", "ốp pen hai mơ" -> "Oppenheimer"
     + "ai dơn men" -> "Iron Man"
     + "xì pai đơ men" -> "Spider-Man"
     + "đa gôn bôn" -> "Dragon Ball"
   - Bóc tách nguồn chỉ định rõ ràng (`ExtractExplicitSource`):
     + "trên youtube", "bằng youtube" -> `ExplicitSource: "youtube"`
     + "trên plex", "từ nas" -> `ExplicitSource: "plex"`
   - Phân loại ý định không dùng API ngoài:
     + Media: `media.search` (slots: `query`, `kind`)
     + Home: `home.control` (slots: `action`, `target_label`, `temperature`)
     + Camera: `camera.control` (slots: `direction`, `privacy`, `speak`, `action`)
     + System: `system.status` (slots: `target`)
     + General: `general.chat` (slots: `text`, `query`)
2. Viết bộ unit test toàn diện trong `understanding_test.go`:
   - "mở chương trình anh trai c2" ->
     `Intent(media.search, query="Anh Trai Say Hi", kind="chương trình")`
   - "tìm phim a ven dơ en gêm trên youtube" ->
     `query="Avengers Endgame"`, `explicit_source="youtube"`
   - Toàn bộ biến thể từ điển ngữ âm và nguồn phát
   - Lệnh điều khiển Home Assistant (đèn, điều hòa chỉnh nhiệt độ, rèm, quạt)
   - Lệnh Camera Tapo (xoay 4 hướng, privacy on/off, phát giọng nói)
   - Lệnh System / NAS status
   - Câu hỏi tự do -> `general.chat`
   - Xử lý timeout và context cancellation
