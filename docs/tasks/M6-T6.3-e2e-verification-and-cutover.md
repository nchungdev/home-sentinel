# Task M6-T6.3: Kiểm thử End-to-End 100 Ca và Chuyển đổi Mặc định

## Mục tiêu
Kiểm thử toàn diện với bộ 100 test case thực tế, chuyển endpoint `/v2/ask` làm mặc định trên TV Launcher
và hoàn thiện quy trình rollback an toàn.

## Nội dung công việc
1. Chạy toàn bộ các bộ Scenario Tests, Contract Tests, và Adapter Tests:
   - Android Unit Tests: 25 task test passed (bao gồm `AgentContractsTest`, `AgentClientV2Test`, `SuggestionPresenterTest`).
   - Go Backend Tests: 15 packages passed (bao gồm `understanding`, `resolution`, `orchestrator`, `adapters/homeassistant`, `adapters/camera`, `proactive`, `telemetry`, `transport`).
   - Python Backend Tests: 49 unit tests passed (bao gồm `test_home_tools.py`, `test_tv_scenarios.py`, `test_agent_server.py`).
2. Kiểm tra TV Client:
   - `AgentClient.kt`: hỗ trợ song song `/v2/ask` (NDJSON stream) và `/ask` (legacy text chunk stream).
   - `AgentActionExecutor`: thực thi an toàn các Intent native `plex.open`, `youtube.launch`, `app.open`.
   - `SuggestionPresenter`: bong bóng gợi ý Home idle sau 10s với tối đa 3 chips, không cướp focus, không auto-TTS.
3. Quy trình Rollback:
   - Backend: Nhờ `LegacyAdapter`, server hỗ trợ đồng thời cả client cũ (`/ask`) và client mới (`/v2/ask`).
   - Client: Nếu endpoint `/v2/ask` gặp sự cố mạng hoặc lỗi phiên bản, client có thể chuyển về `AgentClient.ask` mà không cần sửa cấu trúc UI.
