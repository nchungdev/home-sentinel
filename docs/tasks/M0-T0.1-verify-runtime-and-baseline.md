# Task M0-T0.1: Kiểm tra Runtime NAS, Đối chiếu Go/Python và Baseline

## Mục tiêu
Xác định chính xác tiến trình đang chạy trên NAS, đối chiếu tính năng giữa mã Python (`agent_server.py`)
và Go (`cmd/agent_server/main.go`), chạy toàn bộ test hiện có để lập baseline không suy thoái.

## Nội dung công việc
1. Kiểm tra cấu hình systemd service `tv-agent.service` trên repo và đối chiếu với lệnh thực thi trên NAS.
2. Kiểm tra port 8788 và 8789 (discovery) đang được phục vụ bởi Python hay Go.
3. Chạy toàn bộ test hiện tại trên cả client (`apps/launcher`) và server (`agent`) để ghi nhận kết quả 100% pass:
   - `apps/launcher`: `./gradlew testDebugUnitTest`
   - `home-sentinel/agent`: `python3 -m unittest discover`
   - `home-sentinel`: `go test ./...`
4. Chọn một runtime chính làm chủ pipeline 6 tầng mới (chốt: Python cho logic linh hoạt, tương thích cao với script hiện tại).

## Tiêu chí hoàn thành (DoD)
- Biết chính xác file nào đang chạy trên NAS.
- Mọi test baseline đều đạt 100% trước khi sửa đổi bất kỳ dòng mã nào.
