# Task M3-T3.2: Tách Module Resolution

## Mục tiêu
Xây dựng package Go `resolution` (`home-sentinel/agent/pkg/resolution`) hiện thực interface
`orchestrator.ResolutionEngine`: chuyên trách chuyển đổi `Intent` thành `ActionPlan`
có ID thực tế bằng cách thăm dò dữ liệu từ Plex, Home Assistant và YouTube,
phân định rõ môi trường thực thi (`backend` hay `tv_client`).

## Nội dung công việc
1. Xây dựng package Go `resolution` (`home-sentinel/agent/pkg/resolution`):
   - Hiện thực interface `orchestrator.ResolutionEngine`:
     `Resolve(ctx context.Context, intent *contracts.Intent, reqCtx *contracts.RequestContext)`
     `(*contracts.ActionPlan, error)`
   - Định nghĩa các interface client phụ thuộc (được tiêm vào `Resolver`):
     + `PlexSearcher`: `SearchFirst(ctx context.Context, query string) (*PlexMediaItem, error)`
     + `HAEntityResolver`:
       `ResolveEntity(ctx context.Context, targetLabel string, action string)`
       `(*HAEntityMatch, error)`
   - Logic phân giải Intent Media (`media.search`):
     + Nếu `ExplicitSource == "youtube"` -> ActionPlan `youtube.launch` (runs_on: `tv_client`).
     + Nếu `ExplicitSource == "plex"` -> Gọi `PlexSearcher`:
       - Có phim: ActionPlan `plex.open`
         (runs_on: `tv_client`, deep_link: `plex://...`).
       - Chưa có: ActionPlan kèm bằng chứng `found_in_plex: false`.
     + Nếu không chỉ định nguồn:
       - Phân loại theo `kind` (slot): Nếu là `"chương trình"`, `"show"`,
         `"nhạc"`, `"bài hát"` -> ActionPlan `youtube.launch`.
       - Nếu là phim lẻ/series: Thăm dò Plex trước:
         * Có trong Plex -> ActionPlan `plex.open`.
         * Không có trong Plex -> ActionPlan `youtube.launch`
           (kèm evidence để Presentation hiển thị đa thẻ).
   - Logic phân giải Intent Nhà (`home.control`):
     + Tìm kiếm entity trong Home Assistant qua `HAEntityResolver`.
     + Sinh ActionStep `ha.service_call` (runs_on: `backend`).
   - Logic phân giải Camera (`camera.control`) và System (`system.status`).

2. Viết Unit Tests toàn diện trong `resolution_test.go`:
   - Mock `PlexSearcher` và `HAEntityResolver`.
   - Kiểm thử "Anh Trai Say Hi" (kind: "chương trình") -> Plan mở YouTube.
   - Kiểm thử "Dune 2" (có trong Plex) -> Plan mở Plex với deep link.
   - Kiểm thử "Phim lạ" (không có trong Plex) -> Plan mở YouTube kèm evidence.
   - Kiểm thử lệnh explicit nguồn "trên youtube" và "trên plex".
   - Kiểm thử lệnh Home Assistant khớp entity và lệnh không khớp entity.
   - Kiểm thử context timeout và context cancellation.
   - Kiểm thử camera privacy, ptz, speak, view và system status.
