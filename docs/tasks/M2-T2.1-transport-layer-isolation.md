# Task M2-T2.1: Tách Tầng Transport

## Mục tiêu
Tách biệt hoàn toàn tầng giao tiếp mạng (HTTP server, auth token, deadline, Keep-Alive)
khỏi logic nghiệp vụ xử lý câu hỏi.

## Nội dung công việc
1. Xây dựng package Go `home-sentinel/agent/pkg/transport`:
   - Xác thực Bearer token an toàn bằng so sánh constant-time (`subtle.ConstantTimeCompare`).
   - Kiểm tra IP whitelist (`AGENT_ALLOW`), hỗ trợ IP đơn và dải mạng CIDR.
   - Khởi tạo `contracts.RequestContext` có deadline (15s mặc định hoặc cấu hình).
   - Chặn request thiếu/sai token: HTTP 401 Unauthorized (`{"error": "unauthorized"}`).
   - Chặn request ngoài whitelist: HTTP 403 Forbidden (`{"error": "forbidden"}`).
   - Parse `contracts.InputEvent` từ request body và validate.
   - Hỗ trợ hủy context khi client ngắt kết nối (`r.Context().Done()`).
   - Cung cấp cả `EventHandler`/`TransportHandler` lẫn HTTP middleware.
2. Viết bộ unit test toàn diện trong `transport_test.go` (12 test cases):
   - Missing token -> 401
   - Invalid token -> 401
   - Valid token -> 200
   - IP whitelist filtering (đúng IP, sai IP, CIDR, whitelist rỗng)
   - Parse InputEvent và khởi tạo RequestContext chính xác
   - Body không hợp lệ -> 400 Bad Request
   - Method GET -> 405 Method Not Allowed
   - Client disconnect context cancellation (HTTP 499)
   - Middleware RequestContext injection
   - ConfigFromEnv & ParseAllowedIPs
   - Handler upstream error propagation (500)

## Tiêu chí hoàn thành (DoD)
- Module Transport không chứa từ khóa về Home Assistant, Plex hay Prompt LLM.
- Request không có token hợp lệ bị chặn ngay tại Transport với mã 401.
- IP không nằm trong whitelist bị chặn với mã 403.
- Pass 100% tests, mã nguồn không chứa comment và dòng <= 100 ký tự.
