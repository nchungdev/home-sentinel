# Task M4-T4.1: Mở Endpoint V2 NDJSON

## Mục tiêu
Triển khai endpoint mới `POST /v2/ask` truyền dòng sự kiện có cấu trúc dạng NDJSON (Newline Delimited JSON).

## Kết quả nghiệm thu
- Đã xây dựng `V2Handler` tại `home-sentinel/agent/pkg/transport/v2_handler.go`.
- Hỗ trợ đầy đủ các loại sự kiện chuẩn theo từng dòng NDJSON (`application/x-ndjson; charset=utf-8`):
  1. `accepted`: Xác nhận request_id và session_id ngay lập tức.
  2. `progress`: Báo tiến độ xử lý.
  3. `presentation`: Trả về dữ liệu thẻ card và câu nói ngắn cho TTS.
  4. `client_action`: Lệnh thực thi native trên TV (mở Plex, YouTube).
  5. `completed`: Báo hiệu hoàn tất luồng.
  6. `error`: Báo lỗi chi tiết với mã chuẩn độc lập.
- Bảo vệ an toàn: Bearer token constant-time check, IP whitelist / CIDR check, deadline timeout.
- Unit test `v2_handler_test.go` (4 test cases) đạt 100% PASS.
- Endpoint `/ask` cũ (qua `LegacyAdapter`) tiếp tục hoạt động song song không ảnh hưởng.
