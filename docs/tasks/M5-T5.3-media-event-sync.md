# Task M5-T5.3: Cơ chế Đồng bộ Sự kiện Media Tải Xong

## Mục tiêu
Thiết lập cơ chế đồng bộ sự kiện khi Radarr/Sonarr tải xong phim, lưu trữ có thời hạn trên server
và cho phép TV Launcher kéo về khi trở lại foreground.

## Nội dung công việc
1. Xây dựng `MediaEventStore` trong `agent/pkg/proactive/event_store.go`:
   - Lưu trữ thread-safe các sự kiện tải xong từ Radarr/Sonarr.
   - Quản lý TTL mặc định 24h và tự động thanh lọc các mục hết hạn (`GetActive`).
2. Mở rộng `SuggestionEngine`:
   - Hỗ trợ đầy đủ các khung giờ sinh hoạt (sáng, trưa, chiều, tối, đêm).
   - Tự động sinh `Suggestion` media ready kèm deep link `plex://`.
3. Mở endpoint `GET /v2/suggestions` trong `agent/pkg/transport/v2_suggestions.go`:
   - Xác thực Bearer Token.
   - Trả về danh sách `Suggestion` dạng JSON chuẩn cho TV Launcher kéo về khi `onResume`.
4. Unit tests:
   - `event_store_test.go`: Kiểm tra lưu trữ và thanh lọc TTL 24h.
   - `v2_suggestions_test.go`: Kiểm tra xác thực token và định dạng JSON phản hồi.
