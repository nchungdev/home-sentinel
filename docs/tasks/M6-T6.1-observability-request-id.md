# Task M6-T6.1: Đo lường Xuyên suốt với Request ID

## Mục tiêu
Gắn `request_id` xuyên suốt cả 6 tầng để giám sát và đo lường chính xác độ trễ (latency p50/p99) của từng chặng.

## Nội dung công việc
1. Xây dựng package `agent/pkg/telemetry`:
   - `RequestTrace`: Lưu giữ `request_id`, `session_id`, `layer`, `elapsed_ms`, `status`, `detail`.
   - `LogStructured`: Xuất bản ghi JSON cấu trúc chuẩn trên stdout/logs.
   - Cơ chế bảo vệ riêng tư: tự động ẩn (`[redacted_in_prod]`) nội dung giọng nói khi ở môi trường production.
2. Tích hợp `orchestrator.Process`:
   - Đo lường độ trễ chi tiết từng tầng: `understanding` -> `resolution` -> `execution` -> `presentation`.
   - Ghi nhận trạng thái huỷ (`cancelled`) hoặc lỗi (`failed`) tức thì khi context quá hạn.
3. Unit tests:
   - `tracer_test.go`: Kiểm tra chu trình đo thời gian và che giấu dữ liệu nhạy cảm ở production.
